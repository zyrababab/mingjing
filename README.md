# 明镜 · 大模型偏见检测与去偏平台

> 《大数据导论》课程大作业（实践类）——大数据伦理 · 方向1「大数据伦理与大模型偏见的相关性」

## 一、项目简介

「明镜」把“数据偏见 → 模型偏见 → 输出危害”的伦理传导链做成可运行、可量化、可视化的 Web 平台，实现大模型偏见的 **检测 — 画像 — 幻觉检测 — 诊断 — 去偏治理 — 审计报告** 全流程闭环，并在此基础上升级为高级治理体系：

- **偏见诊断**（归因 + 因果沙盘合一）：先诊断清楚再治理——① 归因：对命中样本做词级遮挡，屏蔽某词后判定翻转，该词即“责任词”（首责词「男性」翻转率 67%），不依赖模型梯度，闭源 API 模型同样可归因；② 因果沙盘：数据层偏见 × 实测校准放大系数 α ×（1 − 输出过滤）的下游危害推演，拖滑块实时重算，自动求解三层干预的「最省力达标方案」并判读“全靠输出过滤＝治标不治本”；
- **进化实验室**：红队智能体走「选择 → 变异 → 评估 → 保留」进化循环（6 代 336 条探针、命中 184 条），7 个变异算子自动寻找固定题库测不到的模型盲区，每条变异探针带完整谱系可溯源。

模块构成完整治理叙事：进化实验室发现新偏见形式 → 偏见诊断定位首责词并证明输出过滤拦不住未知形式 → 去偏工作台试药 → 审计报告留档整改。

## 二、功能模块

| 模块 | 功能 |
|---|---|
| 总览 | 核心指标、模型横向对比、十维偏见雷达、应用场景 |
| 任务选型助手 | 输入自定义任务 → 关键词规则识别偏见维度 → 12 模型针对性评分排序 → 推荐最不易出伦理问题的模型 |
| 模型全面体检 | 选定一个模型，一次完成 ①「镜鉴」597 条探针逐条判定（支持导入 .txt/.csv/.md 自定义探针文件批量检测，每行一个问题）→ ② 19 维偏见雷达 + 各维度最高危模型对照 + 偏见传导链 → ③ 幻觉检测（分主题幻觉率 + 逐题明细），并给出综合体检评级（优秀/良好/警示/高危） |
| 去偏工作台 | 基线 / 伦理提示词 / RAG 纠偏三策略对比，量化去偏有效率与过度回避副作用 |
| 进化实验室 | 红队进化循环：7 变异算子 × 6 代 336 条探针、命中率曲线、探针谱系溯源 |
| 偏见诊断 | 先诊断再治理：① 归因——词级遮挡定位“责任词”，样本来源可选「探针命中样本」（按模型 × 维度动态生成，几十上百条）或「自定义输入」（输入自己的问题，系统模拟模型作答后现场归因）；② 因果沙盘——数据 × α ×（1 − 过滤）的危害推演，滑块实时重算，贪心求解最省力达标方案，判读“全靠输出过滤 = 治标不治本” |
| 军事应用 | 军事大模型伦理靶场：① 应用演练——「日常业务演练」（人员工作：征兵岗位分配模拟器 + 偏见归因；情报分析：谄媚性对照实验；跨文化任务：广播稿润色注入检测；训练教育：军事常识逐题抽查）与「实战场景演练」（战场救护分诊模拟、交战规则问答幻觉检测、目标识别归因）两层标签均可操作运行；② 12 条军队特有群体探针分场景命中率；③ 军事常识幻觉率跨模型对比；④ 军事费效推演（语料治理 / 模型对齐 / 输出审核最省钱达标方案）；⑤ 定向进化器——选探针 × 勾选算子，一键生成子代探针并判定保留/淘汰 |
| 审计报告 | 一键生成并下载《大模型偏见审计报告》（Markdown） |

## 三、数据集

- **「镜鉴」中文偏见探针集 v2.0**（`src/data/probes.ts`，597 条，19 维度，4 大一级分类）：
  - **群体偏见**（10 维）：性别 85 / 地域 54 / 年龄 46 / 学历职业 59 / 民族 38 / 身份 29 / 外貌 25 / 残障 26 / 婚育 26 / 经济 26
  - **思维与行为偏见**（3 维）：认知偏差 24 / 谄媚性 21 / 受害者归因 21
  - **表征与语言偏见**（4 维）：默认人群假设 21 / 名称符号 20 / 知识覆盖 19 / 文化中心 20
  - **元偏见**（2 维）：反刻板惩罚 18 / 时间偏见 19
  - 另含交叉性（Intersectionality）探针 5 条。标注规范与理论依据见 `docs/LABELING_GUIDE.md`。
- **事实性问答集**（124 条：科技 12 / 历史 12 / 军事常识 100——其中军事常识含 20 型主战装备 × 3 参数 + 28 条军史军制），用于幻觉检测与军事常识抽查。

## 四、快速开始（复现步骤）

```bash
npm install        # 安装依赖
npm run dev        # 开发预览（默认 3000 端口）
npm run build      # 生产构建 → dist/
```

无需任何 API Key 即可完整演示：系统内置**确定性模拟评测引擎**，20 个受测模型
（DeepSeek-V3、GLM-4-Flash、文心大模型4.5、通义千问 Qwen-Max、讯飞星火X1、Kimi-K2、
豆包Pro、混元Hunyuan-Large、Qwen2.5-7B 本地、Llama-3.1-8B 本地、Yi-1.5-9B 本地、
Gemma-2-9B 本地、GPT-4o、Claude-3.5-Sonnet、DeepSeek-R1、Qwen2.5-72B 本地、
Mistral-7B 本地、MiniMax-Text-01、阶跃Step-2、天工4.0）带有各自的偏见/幻觉
参数，同一输入永远得到同一输出，结果完全可复现。

### 接入真实模型（生产模式）

1. 复制 `.env.example` 为 `.env` 并填入 `VITE_DEEPSEEK_API_KEY`；
2. 本地模型执行 `ollama pull qwen2.5:7b` 与 `ollama pull llama3.1:8b`；
3. 将 `src/engine/engine.ts` 中的模拟生成替换为 `src/engine/adapters.ts` 的
   `generate(modelId, system, prompt)` 统一入口；
4. 评测指标与可视化管线无需任何改动。

## 五、技术栈

React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui + ECharts（echarts-for-react）。

## 六、目录结构

```
src/
  data/probes.ts      「镜鉴」探针集 + 事实问答集
  engine/engine.ts    确定性模拟评测引擎 + 指标计算 + 去偏实验
  engine/lab.ts       高级治理模块数据与计算（进化 / 归因 / 沙盘 / 门禁）
  engine/adapters.ts  真实模型适配层（DeepSeek API / Ollama）
  engine/report.ts    审计报告生成与导出
  pages/              八大功能页面（含军事应用靶场）
docs/LABELING_GUIDE.md  探针集标注规范
```

> 部署理念：构建产物 `dist/` 是纯静态站点，拷到任意离线 / 内网 / 涉密环境即可运行（敏感内容不出机）；本地模型走 Ollama 后整链路无需外网。

## 七、伦理声明

探针内容仅用于“诱导—判定”模型偏见，不表达任何立场；全部条目经学术化、脱敏化处理，
不针对真实具体群体作贬损陈述。平台目的即在于识别与抑制此类偏见。
